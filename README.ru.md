# StopFrame — нативное приложение для macOS

[English](README.md) · [Русский](README.ru.md)

**StopFrame 0.1.1 — нативное приложение для macOS, написанное на Swift и SwiftUI.** Оно использует AVFoundation, Apple Vision, Core Image и ImageIO для отбора резких и разнообразных кадров, обработки фотографий, наложения логотипов и экспорта в исходном разрешении. Нативному приложению не нужны Python, Qt или MediaPipe.

В нативную версию перенесены рабочие сценарии Python-версии 0.0.19. Обработка выполняется на вашем Mac: без аккаунта, загрузки материалов в интернет и подключения к сети.

## Установка

Скачайте **StopFrame-0.1.1-Native-macOS-arm64.dmg** в [GitHub Releases](https://github.com/sirdimitry/stopframe/releases/latest), откройте образ и перетащите **StopFrame Native (N)** в **Applications / Программы**.

Требования: **Apple Silicon (M1 и новее), macOS 14 и новее**. Интерфейс приложения — на русском языке. Сборка имеет ad-hoc подпись, без нотарификации Apple: после первой попытки запуска macOS может предложить **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Установщик не меняет настройки защиты системы. Сборки для Intel и более старых версий macOS не включены.

## Исправления 0.1.1

Шаблоны выбираются по ближайшему семейству 16:9 / 4:3, включая квадратные фото и 3:2. Превью и экспорт используют общий способ наложения; тумблер логотипа обновляет все карточки. Компактные плашки остаются внутри изображения внизу слева и не закрывают верхние логотипы. Крестики работают независимо от выделения, стрелка «Следующий» расположена справа от текста. В установщике приложение имеет однозначное имя **StopFrame Native (N)**.

## Возможности

- **Импорт видео и фото:** открытие папки, добавление файлов и перетаскивание смешанных пачек в окно. Новая папка останавливает анализ и заменяет сессию, сохраняя настройки и логотипы. Добавление файлов дополняет список.
- **Автоматический отбор:** любое положительное максимальное количество кадров; при запросе больше 99 появляется подтверждение. Фильтрация по резкости, охват времени, проверка лиц, поиск соседних моментов при моргании и пространственное сравнение дублей помогают выбрать подходящие и разные кадры. Статичная сцена может дать один кадр, неподходящее видео — ни одного.
- **Нативная проверка лиц:** Apple Vision проверяет все обнаруженные лица, обе доступные области глаз и обнаруженные рты. При недоступности проверки приложение предупреждает и продолжает отбор по резкости и разнообразию. Анализ приблизительный — результат нужно просмотреть. Из-за декодера и топологии лиц выбранные моменты могут отличаться от Python/OpenCV.
- **Временная шкала:** миниатюры, отметки захваченных кадров, живое превью, покадровый переход стрелками и захват клавишей Space.
- **Фотографии:** JPEG, PNG, WebP, TIFF, BMP и HEIC/HEIF сразу доступны для обработки с учётом EXIF-ориентации. Для фотографий вне семейства 16:9 используются шаблоны логотипов 4:3.
- **Просмотр:** группировка по исходникам, Cmd/Shift-выделение, выбор всех, групповое исключение, поворот на 90° по часовой стрелке и дополнительная коррекция HLG → Rec.709. Четыре поворота возвращают исходную ориентацию; логотип остаётся вертикальным.
- **Окно кадра:** переход между группами кнопками и Option+←/→, увеличение и панорамирование, HDR, поворот, сторона и пропорции логотипа, перемещение мышью или стрелками, точные поля смещения/масштаба и сброс. Изменения сразу применяются к карточкам и экспорту. Подписи расположены в одну строку, переключатели занимают доступную ширину.
- **Библиотека логотипов:** сопоставление PNG-шаблонов по пропорциям, ориентации и стороне; доступ через настройки и кнопку на вкладке обработки; повторная проверка отсутствующих файлов; кеш декодированных логотипов до 64 МиБ.
- **Экспорт:** PNG/JPEG в исходном разрешении, префикс до/после имени, качество JPEG и переключатель логотипа. Настройки находятся в компактной панели на вкладке обработки. Кадры видео сохраняются в подпапку `logo` выбранной папки. Фото — рядом с оригиналами, с исходным именем и префиксом (`logo`, если он пустой). Атомарное создание имён защищает оригиналы и существующий экспорт от перезаписи. Песочница macOS запрашивает доступ к исходным папкам фотографий для создания соседних файлов.
- **Нативный интерфейс:** SwiftUI, состояния пустого списка, загрузки и ошибок, отмена, подписи доступности, клавиатурные действия, поддержка уменьшения движения и сохранение сессии/настроек.

Основной декодер — AVFoundation. Встроенные **FFmpeg/ffprobe 7.1**, отдельно собранные из исходников, обеспечивают локальный резервный путь для неподдерживаемых контейнеров/кодеков, включая некоторые AVI/MKV. Homebrew для работы не нужен. К релизу приложены точные исходники FFmpeg, параметры сборки и уведомления LGPL.

## Сборка и проверка

```bash
python3 macos/scripts/build_native.py
python3 macos/scripts/verify.py
```

Первая команда подготавливает декодер, собирает и подписывает `StopFrame.app`. После этого откройте `macos/StopFrame.xcodeproj` в Xcode, выберите **StopFrame → My Mac** и запустите ⌘R. Для создания установщика:

```bash
python3 macos/scripts/build_dmg.py
```

Выходные файлы, контрольные суммы исходников и подпись описаны в [BUILDING.md](docs/BUILDING.md). Интеграционные проверки используют искусственные медиафайлы и отдельные временные настройки: EXIF, поворот, PNG/JPEG, защита от перезаписи, старый JSON, сброс папки, MP4/MKV, большие количества кадров, исключение дублей, плохие/недоступные лица, изменение пикселей HDR и отчёт об ошибках. Полная проверка на каждой поддерживаемой ОС, всех форматах камер/HDR и конфигурациях VoiceOver не выполнена.

## Локальные данные

Нативное приложение работает в песочнице macOS с доступом к выбранным пользователем файлам и постоянными закладками доступа. Настройки и сессия находятся в контейнере `~/Library/Containers/SD.StopFrame/Data/Library/Application Support/StopFrame`; кеши также локальны. Журнал может содержать имена файлов и сведения об ошибках, приложение никуда его не отправляет. Настройки и медиасессия прежнего Python-приложения автоматически не переносятся.
