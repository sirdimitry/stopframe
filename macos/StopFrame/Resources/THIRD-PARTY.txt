The full license, FFmpeg notices and exact build configuration are included
in Licenses/ and in the source repository. No GPL or nonfree option or
third-party codec library is enabled; the helpers use Apple's system zlib.
Build recipe: macos/scripts/build_ffmpeg.py in the StopFrame repository.
No FFmpeg source modifications were made. Codesigning changes Mach-O code
signatures only. The binaries can be replaced with compatible builds from
these sources in an independently signed copy of the application.
FFmpeg is a separate local subprocess fallback; the app uses AVFoundation first.
